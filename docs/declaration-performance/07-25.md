Steps 07–25 extend the existing declaration emitter, parser, compiler host and editor snapshot machinery. They remove avoidable work, tighten ownership, and establish the producer/project-reference boundary needed for a later automatic declaration fallback. They do **not** enable that fallback, replace the declaration printer, introduce a signature-only parser, or make arbitrary dependency implementations collectible from a live Program.

The [raw measurements, build provenance and reproduction instructions](evidence-07-25/REPRODUCE.md) accompany this report.

Editor timings exclude declaration generation, producer edits, JSON/socket transport and automatic fallback. Logging, watchers, push diagnostics, ATA and auto-import warming are disabled. Queue draining bounds historical snapshot retention and includes its own scheduling overhead in both arms. Old snapshots release normally; concurrent outstanding requests are not modeled. An editor extraction break-even cannot be inferred from the fresh-Program generation benchmark: extraction caching, producer invalidation and miss costs still need measurement in the integrated session path.

Two `ipc` tests could not create Unix sockets (`operation not permitted`). These were not compiler output or baseline mismatches.

Existing in-tree tests and the added tests support unchanged declaration/API output for the covered inputs. Weak-reference and cache-ownership checks demonstrate specific references being released; they do not prove that all dependency implementations can be collected from a live editor project.

The next concrete feature should synthesize a missing referenced project's normal declaration output in memory. This uses a boundary where declaration-file semantics already apply. Using public `.d.ts` text as an internal signature for arbitrary source dependencies requires separate equivalence tests for private generic information, const-enum restrictions, body-only augmentation reachability and `stripInternal`. A producer’s `isolatedDeclarations` setting does not by itself establish equivalence for all of those cases.
